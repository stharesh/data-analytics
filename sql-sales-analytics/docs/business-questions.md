# Business Questions

This project is organized around recurring sales-reporting questions rather than isolated SQL syntax exercises.

1. What are monthly and yearly gross sales for a selected customer?
2. Which markets generate the highest sales?
3. What is each customer's contribution to net sales?
4. Which products rank highest within each division?
5. What is regional market share?
6. How accurate are sales forecasts compared with actual quantities?
7. Which markets qualify for a performance badge based on sold quantity?
8. How can frequently filtered queries be optimized on a large fact table?
