# Data Analytics Portfolio

Portfolio of end-to-end Data Analytics projects using SQL, Excel, Power BI, Python, and DAX, focused on solving real business problems.

## Featured Project

### [SQL Sales Analytics & Query Optimization](./sql-sales-analytics/)

A MySQL project analyzing a 1.4M+ row sales dataset across customers, products, markets, pricing, deductions, costs, and forecasts. The project demonstrates business-focused SQL analysis, reusable views, stored procedures and functions, advanced SQL techniques, and query-performance optimization using indexes and `EXPLAIN ANALYZE`.

**Highlights:**
- 1,425,706 records in `fact_sales_monthly`
- 4 analytical views
- 9 stored procedures identified in the source work
- 2 SQL functions for fiscal-period logic
- CTEs, subqueries, temporary tables, joins, and window functions
- Indexing and execution-plan analysis
- Customer, market, product, and forecast analysis

More projects will be added as the portfolio is organized and refined.
